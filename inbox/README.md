# 受信箱（DMとコメント）の準備

Instagram に届いた DM とコメントを、**15分ごとに Google スプレッドシートの「受信箱」シートに並べる**仕組みです。

- 新しく届いたものは Claude が分類（初参加の相談／日程・会場の質問／その他／返信不要）し、**返信の下書き**を書きます
- **初参加の相談が新しく来たときだけ**、メールで知らせます（件名は「初参加の相談 1件（返信期限 10/9 21:00）」のように件数と期限だけ）
- **送るのはあなたです。** 下書きを直して、Instagram のアプリから手で送ります。自動では送りません
- 管理ボードの「受信箱」には、**件数・優先度・期限だけ**が出ます。本文と名前はこのシートの中だけにあります

動くのはあなたの Google アカウントの中（Apps Script）です。GitHub Actions には乗せていません（Actions のログは公開されるため）。

---

## 準備（1回だけ・30分くらい）

### 1. Instagram の権限を足して、トークンを取り直す

1. Meta for Developers → アプリ → Instagram →「API setup with Instagram login」を開く
2. 権限に次の2つを足す（いまある権限はそのまま）
   - `instagram_business_manage_messages`（DM を読む）
   - `instagram_business_manage_comments`（コメントを読む）
3. 「Generate token」でトークンを取り直す（Instagram のアカウントで許可する画面が出る）
4. GitHub → Settings → Secrets and variables → Actions → `IG_ACCESS_TOKEN` を新しいトークンに更新する
   （投稿と数字の取り込みも同じトークンなので、更新したあともそのまま動きます）
5. Instagram のアプリ → 設定 →「メッセージとストーリーへの返信」→「メッセージのコントロール」→
  「つながっているツール」→ **「メッセージへのアクセスを許可」をオン**

### 2. スプレッドシートを作って、スクリプトを貼る

1. Google ドライブで、新しいスプレッドシートを作る（名前は「遊部 受信箱」など）。**だれとも共有しない**
2. メニューの「拡張機能」→「Apps Script」を開く
3. 左の「ファイル」に、このフォルダの `apps-script/` にある3つを同じ名前で作り、中身をそのまま貼る
   - `Rules.gs`・`Services.gs`・`Main.gs`（最初からある `コード.gs` は消してよい）
4. 左の歯車（プロジェクトの設定）→「`appsscript.json` マニフェスト ファイルをエディタで表示する」をオン →
   出てきた `appsscript.json` に、このフォルダの `apps-script/appsscript.json` の中身を貼る
5. 保存する

### 3. 鍵を「スクリプト プロパティ」に入れる

歯車（プロジェクトの設定）の下のほう →「スクリプト プロパティ」→「スクリプト プロパティを追加」で、次を入れます。
**ここ以外（コードやシート）には書かないでください。**

| プロパティ | 中身 | 取り方 |
|---|---|---|
| `IG_ACCESS_TOKEN` | 手順1で取り直したトークン | GitHub に入れたものと同じ |
| `ANTHROPIC_API_KEY` | Claude API のキー | console.anthropic.com → API Keys → Create Key。**Limits で月の上限額も決めておく** |
| `GITHUB_TOKEN` | 件数をボードに出すためのトークン | 下の「GitHub のトークン」 |
| `NOTIFY_EMAIL`（任意） | 通知の宛先 | 省くと、このスプレッドシートの持ち主のアドレス |

**GitHub のトークン**（fine-grained personal access token）：
GitHub → 右上のアイコン → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token

- Repository access：**Only select repositories** → `asobu-instagram-drafts-` だけ
- Permissions → Repository permissions → **Contents：Read and write**（ほかは触らない）
- Expiration：1年など。切れたら作り直して入れ替える

> ⚠️ このトークンは main にも書けてしまいます。main の保護（PRを必須にするルールセット。data ブランチは対象外）を
> まだ作っていなければ、先に作ってください。スクリプトが書くのは data ブランチの `inbox-summary.json` だけです。

### 4. 動かす

1. スプレッドシートを開き直すと、メニューに「**遊部の受信箱**」が出ます
2. 「はじめの準備（1回だけ）」を押す → 許可を求める画面が出る →
  「詳細」→「（安全ではないページ）に移動」→ 許可（自分で作ったスクリプトなので、確認済みの表示が出ません）
3. 「設定を確かめる」を押す。6つとも ✅ になれば準備は終わりです
4. 「今すぐ取り込む」を押すと、すぐに1回取り込みます。あとは15分ごとに自動で動きます

❌ が出たら：

| 出たところ | 直し方 |
|---|---|
| Instagram のトークン | トークンが違うか期限切れ。手順1の3から |
| DM を読む権限 | `instagram_business_manage_messages` が無いか、「メッセージへのアクセスを許可」がオフ（手順1の2・5） |
| コメントを読む権限 | `instagram_business_manage_comments` が無い（手順1の2） |
| リポジトリの規則書 | GitHub が一時的に読めないだけのことが多い。少し待って押し直す |
| Claude API | キーの打ち間違いか、Anthropic の支払い設定がまだ |
| GitHub のトークン | リポジトリの選び忘れか、Contents が Read only のまま |

## ふだんの使いかた

1. 「初参加の相談」のメールが来たら、スマホの Google スプレッドシートのアプリで受信箱シートを開く
2. 上から順に並んでいます（返信待ち → 初参加 → 日程・会場 → その他。同じなかでは期限の近い順）
3. 「下書き」をコピーして、`【日程と会場】`・`【参加の案内】` などを埋めて、Instagram のアプリから送る
4. 送ったら、次の取り込みで「返信済み」になります（DM とコメントは自動で分かります）。
   コメントに DM で返したときなどは、「状態」を手で「返信済み」か「対応不要」にしてください

シートの見かた：

| 列 | 中身 |
|---|---|
| 優先度 | 初参加の相談／日程・会場の質問／その他／返信不要 |
| 状態 | 返信待ち／返信済み／対応不要（手で変えてよい。新しいメッセージが来たら返信待ちに戻る） |
| 期限 | 相手の最後のメッセージから24時間の目安 |
| 下書きの検査 | `OK` か `要手直し：…`（会場名・LINE・人数・使わない言い回しが入っていたとき） |
| 送る前にやること | 埋める空欄や、確かめること |

「動き」シートに、取り込みのたびに1行（何件あったか、失敗したら理由）が残ります。

## 知っておくこと

- **分類と下書きの規則**は、リポジトリの `.claude/agents/staff/inbox-triager.md` と CLAUDE.md の §1（事実表）を
  main から読んで使います。規則を直すときはそのファイルをPRで直せば、シートは6時間以内に新しい規則で動きます
- **スクリプトを直したとき**（`inbox/apps-script/` が変わったPRをマージしたとき）は、手順2の3の貼り直しが要ります
- **Claude が使えないとき**（キー切れ・混雑）は、言葉だけで仮に分類して、下書きは空のまま並べます。止まりはしません
- **費用**：Claude（`claude-opus-5-5`・思考の深さは低め）を、新しく届いたメッセージ1通ごとに1回呼びます。
  1回あたり数円の見込みです。断られたときは、Anthropic が勧める別のモデルで自動でやり直す設定（`fallbacks`）にしてあります
- **トークンの期限**：Instagram の長期トークンは約60日で切れます。取り直したら、GitHub の `IG_ACCESS_TOKEN` と
  スクリプト プロパティの両方を入れ替えてください
- ⚠️ 要確認：**メッセージリクエスト**（フォローしていない人からの DM）が API で取れるかは、まだ確かめていません。
  取れない場合は、Instagram のアプリでリクエストを承認すると、次の取り込みからシートに出ます
