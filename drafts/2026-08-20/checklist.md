# 投稿前チェックリスト｜初参加で気になる3つのこと

## 事実確認

- [ ] 投稿内の会場表記が「主に和歌山市立松下体育館」または当日の実態に合っている。
- [ ] 投稿内の時間が「土日 19:00〜21:00」または当日の実態に合っている。
- [ ] 投稿内の費用が「1回600円」または当日の実態に合っている。
- [ ] プロフィールのリンク先に最新の日程・参加方法が載っている。

## 素材・文章

- [ ] 未確認の参加人数、実在者の感想、開催確定前の日程は書かない
- [ ] 識別できる参加者の写真を使う場合は投稿許可を確認する
- [ ] 会場・時間・参加費は投稿前に実態と一致するか確認する
- [ ] 『バドミントン』を正式表記として使う
- [ ] 7枚の画像が「表紙 → 詳細ポイント → 基本情報 → 参加導線」の順になっている。
- [ ] `caption.md`の「画像ごとに紹介していること」と画像2〜6枚目の内容が一致している。
- [ ] ハッシュタグが投稿テーマと地域に合っている。
- [ ] 『バトミントン』の誤表記がない。

## 投稿後

- [ ] 実際の投稿日・URL・反応を`published/2026-08-20.md`へ記録する。
